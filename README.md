# MiqiPet Homebrew Tap

[MiqiPet](https://miqi.dev) 是一只桌面宠物，显示 Claude Code、Codex、OpenCode、Cursor 等 agent 正在做什么。

MiqiPet is a desktop pet that shows what your coding agents are doing.

## 安装 / Install

```bash
brew install miqipet/tap/miqipet
```

需要 Apple Silicon 的 Mac，macOS 11 或更高版本。安装后 app 自己检查更新，也可以用 `brew upgrade --greedy miqipet/tap/miqipet`。

Requires an Apple Silicon Mac running macOS 11 or later. The app updates itself; `brew upgrade --greedy miqipet/tap/miqipet` works too.

## 卸载 / Uninstall

```bash
brew uninstall --cask miqipet/tap/miqipet          # 加 --zap 同时删除配置 / add --zap to remove settings as well
```
